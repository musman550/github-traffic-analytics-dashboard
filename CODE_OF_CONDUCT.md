# Code of conduct

Be respectful and constructive. Harassment, personal attacks, spam and posting other people's private
information are not tolerated in Issues, Pull Requests or Discussions. The maintainer may edit, hide or delete
contributions and block accounts that break these rules. Report problems through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

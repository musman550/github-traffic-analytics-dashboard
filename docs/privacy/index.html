Dashboard / Privacy

Privacy

This site collects no personal data of its own. Details below.

What this site does not do

  • No analytics, advertising or tracking scripts, and no cookies set by this site.
  • Private repositories are never read, stored or published.
  • No accounts or logins are needed to view anything.

What is stored in your browser

Only your light or dark theme choice, saved locally in your browser. It is never sent anywhere.

Published data

The dashboard publishes public information about public repositories (names, descriptions, topics, stars, forks) together with the owner's traffic statistics, and the links found on the owner's public GitHub profile.

AI optimizer

The optimizer sends the public README, description, topics and top-level file names of a public repository to AI providers that serve open-weight models (for example Groq, Cerebras, GitHub Models, OpenRouter, Hugging Face, Mistral and Cloudflare Workers AI). Private repositories are never read. Providers apply their own terms and may log requests; free tiers may use inputs for training, which is another reason only public text is sent.

Hosting

The site is served by GitHub Pages. GitHub may process technical request data such as IP addresses under the GitHub General Privacy Statement.

Comments

The Comments tab loads giscus in an embedded frame, only when you open that tab. Comments are public GitHub Discussions posts under the commenter's GitHub account and are subject to GitHub's terms. Posting requires signing in to GitHub; reading does not.

Contact

Use GitHub Discussions. Security issues can be reported privately through the repository's security advisories.

GitHub Traffic Analytics Dashboard

Permanent history of GitHub views, clones, referrers and stars for public repositories. Open source, free and login-free.

Dashboard / Open data

Open data

All numbers on this dashboard are published as static files. They are updated daily and free to use under the MIT license; attribution is appreciated.

Files

FileContents
summary.jsonDashboard data: totals, daily/weekly/monthly/yearly series, repository table, sources, insights, languages, topics. Daily rows are [date, views, unique views (summed per repo), clones, unique clones (summed)].
series.jsonPer repository history: {"repos": {name: {"views": {"YYYY-MM-DD": [count, uniques]}, "clones": {...}, "win": {...}}}}. Days without traffic are omitted.
repos.jsonPublic repository metadata: description, topics, language, license, stars, forks, dates.
sources.jsonReferrer snapshots: by_date totals (14-day windows) and top referrers and paths per repository.
totals_history.jsonDaily totals: [date, repositories, stars, forks, watchers, open issues].
profile.jsonPublisher profile and public links collected from GitHub.
repos.csvRepository table as CSV (views, clones, stars, language, license, score).
daily.csvDaily views and clones across all repositories as CSV.
health.jsonStatus of the last collection run.

Current snapshot

276 public repositories; data from 2026-10-30 through 2026-11-17; generated 2026-11-19T03:49:55+00:00.

Example

import requests
s = requests.get("https://musman550.github.io/github-traffic-analytics-dashboard/data/summary.json", timeout=30).json()
print(s["totals"]["views_30d"], "views in the last 30 days")

Badges

Endpoint files for Shields.io are available at https://musman550.github.io/github-traffic-analytics-dashboard/badges/views-30d.json, repos.json, stars.json and clones-30d.json.
